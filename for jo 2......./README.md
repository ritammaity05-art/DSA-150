# 150 STRICKs - Powered by Ritam ⚡

Welcome to **150 STRICKs**! This is a modern full-stack web application built with **Next.js (React + TypeScript)** on the frontend and **Python Django REST Framework** on the backend.

> ⚠️ **Note**: Because this is a Next.js + Django full-stack application, **"Open with Live Server" will not work**. Follow the 2 simple steps below to run it inside VS Code!

---

## 🚀 How to Run in VS Code (Step-by-Step)

### Step 1: Open VS Code Terminal
In VS Code, click **`Terminal`** ➔ **`New Terminal`** from the top menu bar (or press `Ctrl + ~` / `Cmd + ~`).

---

### Step 2: Start the Website (Frontend)
In the VS Code terminal, run:

```bash
cd frontend
npm run dev
```

Now open **[http://localhost:3000](http://localhost:3000)** in your Chrome/Safari browser! 🌐

---

### Step 3: Start the Backend (API Server)
Open a second terminal tab in VS Code (click the `+` icon in terminal) and run:

```bash
cd backend
source venv/bin/activate
python manage.py runserver 8008
```

Backend API is now live at **[http://localhost:8008/api/problems/](http://localhost:8008/api/problems/)** ⚡

---
